# Photo Viewer v2.0.1 installer build

- Installer: `PhotoViewer_v2.0.1_Setup.exe`
- Supports per-user and all-users installation.
- Existing installations are removed by the installer before installing this version.
- Settings are stored separately at `%LOCALAPPDATA%\Photo Viewer\2.0.1\settings.json`.
- If no v2.0.1 settings exist, v2.0.0 settings are copied without deleting the old file.
