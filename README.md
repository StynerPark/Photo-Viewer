# Photo Viewer v2.0.1

Photo Viewer는 Windows용 이미지·영상 뷰어이자 폴더 탐색기입니다. 로컬 및 SMB/UNC 폴더 탐색, 단일·2장·3장·웹툰 보기, 애니메이션 이미지, VLC 기반 영상 재생을 지원합니다.

## 다운로드

최신 설치 파일은 [GitHub Releases](https://github.com/StynerPark/Photo-Viewer/releases/latest)에서 받을 수 있습니다.

- 설치 파일: `PhotoViewer_v2.0.1_Setup.exe`
- 이전 등록 정리 도구: `PhotoViewer_DefaultApp_Reset_v1.0.8.exe`
- Windows 10/11 x64
- 현재 배포 파일은 코드 서명이 없으므로 Windows SmartScreen 안내가 표시될 수 있습니다.

## v2.0.1 핵심 변경

- 파일 목록 우클릭 메뉴의 Delete와 Properties 사이에 포맷 변환과 영구 회전을 추가했습니다.
- JPG, PNG, WebP, AVIF, BMP, TIFF 변환과 품질·압축률·출력 폴더·예상 용량을 지원합니다.
- 기본 단축키는 포맷 변환 `Ctrl+Shift+F`, 영구 회전 `Ctrl+Shift+R`이며 메뉴에도 표시됩니다.
- 변환과 회전은 백그라운드에서 순차 처리하고 임시 파일 저장에 성공한 뒤에만 결과 파일을 교체합니다.
- v2.0.0 설정을 복사해 시작하되 v2.0.1 설정과 이전 버전 설정은 서로 분리해 보존합니다.
- 패키지 첫 실행을 막던 ImageQt import 순서와 외부 ICU·VC 런타임 충돌을 수정했습니다.

## v1.0.8 핵심 변경

- 사진에서 선택한 Fit 모드를 영상에도 같은 계산으로 적용해 같은 원본의 사진·영상 표시 크기가 달라지지 않게 했습니다.
- 라이트 테마의 Mode·Fit 팝업에도 뷰어 오버레이 전용 고대비 색상을 적용했습니다.
- Direct3D11 영상 출력을 유지하면서 전체 화면 영상 표면이 중앙 영역을 정확히 채우도록 검증해 하단 잘림을 차단했습니다.
- 영상 전환마다 깨끗한 VLC 플레이어와 네이티브 출력 표면을 배정해 이전·다른 영상의 첫/마지막 프레임이 섞이지 않게 했습니다.
- 새 영상의 실제 출력이 확인될 때까지 검정 로딩 커버를 유지하고, 사용이 끝난 플레이어는 UI 스레드 밖에서 낮은 우선순위로 정리합니다.
- VLC 초기화·시작·정리 작업을 분리하고 대기 중인 영상 슬롯을 자동 재개해 싱글·듀얼·트리플 및 무한 반복을 동일하게 처리합니다.
- 실제 번들 VLC 혼합 전환에서 외부 출력창 0개, 깨끗한 플레이어·표면 배정과 올바른 GIF 전환을 확인했습니다.
- 360개 파일 실측에서 캐시 재진입 시 폴더 재스캔 0회, 탭·보기 모드·뷰어 복귀 때 폴더 트리와 분할 크기 보존을 확인했습니다.

## v1.0.7 핵심 변경

- 창 모드와 최대화 모드에서 좌측 상단에 항상 표시되던 검은 파일명 배지를 제거했습니다.
- 파일명은 기존 상단 중앙 오버레이에서만 확인할 수 있으며 VLC 영상 출력창 차단 수정은 그대로 유지됩니다.
- 실제 빌드 화면과 이미지·영상 교차 전환을 함께 검사했습니다.

## v1.0.6 핵심 변경

- 영상과 이미지를 섞어 이동할 때 독립 `VLC (Direct3D11 output)` 창이 나타나는 경쟁 상태를 제거했습니다.
- 싱글·듀얼·트리플 모드의 VLC 플레이어와 네이티브 영상 표면을 최대 3개까지 같은 순서로 영구 재사용합니다.
- 화면 전환 중 살아 있는 플레이어의 출력 HWND를 `0`으로 분리하지 않으며, 뷰어 종료 때만 `stop → 분리 → release` 순서로 정리합니다.
- 실제 번들 VLC로 안정 전환과 140ms 고속 혼합 전환을 검사해 예상 밖 최상위 창 0개를 확인했습니다.

## v1.0.5 핵심 변경

- 영상 사이를 이동하거나 무한 반복으로 재시작할 때 새 영상의 실제 출력이 준비될 때까지 검은 로딩 덮개를 유지합니다.
- 재사용한 VLC 네이티브 표면에 남아 있던 이전 영상 프레임이 약 1초 노출되는 문제를 차단했습니다.
- 빠른 연속 이동에서 이전 영상의 늦은 출력 이벤트가 현재 영상의 덮개를 잘못 해제하지 못하도록 세대·재생 토큰을 검증합니다.
- 싱글·듀얼·트리플 슬롯 재사용과 기존 배속·무한 반복 동작은 그대로 유지합니다.

## v1.0.4 핵심 변경

- 영상 하단 바의 Stop과 무한 반복 사이에 `1.0x` 배속 메뉴를 추가했습니다.
- `0.25x`, `0.5x`, `0.75x`, `1.0x`, `2.0x` 프리셋과 `0.1x`~`4.0x` 직접 입력을 지원합니다.
- 싱글·듀얼·트리플 모드의 모든 활성 영상, 다음 영상, 반복 및 정지 후 재생에도 선택 배속을 다시 적용합니다.
- 애니메이션 GIF·WebP·APNG의 회전 바 오른쪽에도 동일한 배속 메뉴를 표시하고 정적 WebP에는 표시하지 않습니다.
- 애니메이션 WebP의 ANMF 프레임 시간을 읽어 원본 속도와 선택 배속을 정확히 반영합니다.
- 배속은 실행 중 다음 파일에도 유지되며 프로그램을 다시 실행하면 `1.0x`로 시작합니다.

## v1.0.3 핵심 변경

- 상세·목록 보기에 확장자별 연한 행 색상을 적용하고 라이트·다크 테마별 명도를 분리했습니다.
- 작은·중간·큰 썸네일 오른쪽 아래에 실제 확장자를 표시하는 색상 배지를 추가했습니다.
- 선택·호버 하이라이트는 확장자 색상보다 우선 표시됩니다.
- 썸네일 보기의 휠을 한 칸당 3행으로 가속하고 터치패드 픽셀 입력 속도를 높였습니다.
- 보기 변경 시 폴더를 다시 검색하거나 썸네일을 다시 디코딩하지 않습니다.

## v1.0.2 핵심 변경

- 다른 폴더의 이미지를 외부 더블클릭으로 연 뒤 뷰어를 닫으면 새 이미지의 폴더와 목록으로 복귀합니다.

## v1.0.1 핵심 변경

- 설치형 제품명, 창 제목, 실행 파일과 Windows 메타데이터를 `Photo Viewer` / `PhotoViewer.exe`로 통일했습니다.
- 설정은 버전별 `%LocalAppData%\Photo Viewer\<버전>\settings.json`에 저장하므로 여러 버전의 설정이 공존합니다.
- 해당 버전 설정이 없으면 기존 `%LocalAppData%\Photo Viewer\settings.json`을 먼저 복사하고, 그것도 없으면 `%LocalAppData%\Portable Photo Viewer\settings.json`을 한 번 자동 복사합니다. 원본 설정은 삭제하지 않습니다.
- 설치 완료 후 Windows 기본 앱 설정 화면을 자동으로 열지 않습니다.
- 설치할 이미지 확장자 39개를 사용자가 선택할 수 있으며 영상 확장자는 등록하지 않습니다.
- 사용자용과 전체 사용자용 중복 설치를 차단합니다.
- 연결된 이미지를 더블클릭하면 뷰어가 전면으로 열립니다.
- 단일·2장·3장 영상 슬롯의 재생, 무한 반복과 빠른 영상 전환을 유지합니다.
- 뷰어 삭제 후 탐색기로 강제 전환하지 않고 다음 미디어를 계속 표시합니다.
- 탐색기 폴더 트리 구조와 사용자가 조절한 스플리터 크기를 유지합니다.
- 폴더 진입·복귀·탭 전환·썸네일·모드 전환 작업의 비동기 처리와 취소 로직을 유지합니다.
- 웹툰 모드의 원본 종횡비, 가시 영역 우선 로딩과 제한된 캐시를 유지합니다.
- 처음/끝에서 휠·PageUp·PageDown 입력은 현재 미디어를 다시 로드하지 않는 no-op입니다.

전체 변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 참고하십시오.

## 주요 기능

- Windows 스타일 폴더 트리, 다중 탭, 주소 입력과 빠른 검색
- 상세·목록·중간·큰 아이콘 보기와 이름·크기·형식·날짜 정렬
- 단일·더블·트리플·웹툰 뷰어 모드
- GIF, Animated WebP, APNG 재생
- VLC/libVLC 영상 재생, 탐색, 음량, 정지와 무한 반복
- 이미지 확대·축소·회전·맞춤과 잠금
- 복사·잘라내기·붙여넣기·이름 변경·휴지통 삭제
- 라이트/다크 테마와 사용자 단축키
- 단일/다중 인스턴스 실행

## 설치 및 연결

설치기는 현재 사용자 또는 모든 사용자를 선택하고, 설치 경로와 연결 후보 이미지 확장자를 지정할 수 있습니다. Windows 10/11은 기본 앱 확정을 사용자 선택으로 보호하므로 필요한 경우 이미지 파일을 더블클릭하고 `Photo Viewer`를 선택하십시오.

이전 공개판이나 시험판의 등록을 먼저 지우려면 릴리스의 `PhotoViewer_DefaultApp_Reset_v1.0.8.exe`를 실행하십시오. 사진, 사용자 설정과 다른 앱 등록은 삭제하지 않습니다.

## 소스 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

영상 재생에는 VLC 3.x x64 런타임이 필요합니다. `main.py` 옆의 `vlc` 폴더 또는 `PMV_VLC_SOURCE` 환경 변수로 런타임 경로를 제공합니다.

## EXE 빌드

```powershell
$env:PHOTO_VIEWER_VLC_SOURCE = 'C:\path\to\vlc'
python build_exe.py
```

결과는 `dist\PhotoViewer\PhotoViewer.exe`에 생성됩니다. 설치기 빌드에는 Inno Setup 7이 필요하며 `installer\PhotoViewer.iss`를 컴파일합니다.

## 테스트

```powershell
python tests/run_all.py
```

회귀 테스트는 미디어 끝점 no-op, 빠른 탐색, 웹툰 비율, 애니메이션 워커, 탐색기 복원, 세션 모드, 전면 실행, 뷰어 삭제, UI 구조, 탭 상태, 비동기 스캔·썸네일·VLC와 무한 반복을 검사합니다.
